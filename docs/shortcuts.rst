Keyboard shortcuts
==================

Viewer defaults
---------------

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - Key
     - Action
   * - :kbd:`Left Arrow` or :kbd:`A`
     - Previous frame
   * - :kbd:`Right Arrow` or :kbd:`D`
     - Next frame
   * - :kbd:`Space`
     - Toggle reviewed
   * - :kbd:`F`
     - Toggle favorite
   * - :kbd:`R`
     - Toggle rejected
   * - :kbd:`Escape`
     - Close the viewer

Gallery shortcuts include select visible, clear selection, open selected,
undo, and redo. Open **Settings** to inspect or change them. Frame Studio rejects
conflicting assignments and stores preferences in the current browser.

Labels can have their own unique shortcuts. A label key applies to the current
selection or open frame. Shortcuts are ignored while focus is inside an input,
textarea, or select so normal typing remains safe.
